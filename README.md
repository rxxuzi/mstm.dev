# mstm.dev

**Build. Break. Create.**

A community-driven collection of developer tools, digital art, and interactive experiments. Everything runs in your browser, everything is open source, and everything is free.

## 🌟 Vision

Developer tools are scattered across the web. Every project reinvents the same utilities. Every developer bookmarks dozens of sites.

**mstm.dev** changes that. One platform where the community builds tools together. One place to find, use, and contribute utilities that actually work.

## 🚀 Features

- **Developer Tools**: Image converters, hex editors, code formatters, and more
- **Digital Art**: Generative art, visualizations, interactive experiences
- **Games & Experiments**: Browser-based games and creative projects
- **Community-Driven**: Anyone can contribute via pull request
- **Open Source**: All code is public and transparent
- **No Paywalls**: Everything is free, forever

## 🏗️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Hosting**: Vercel
- **Analytics**: Vercel Analytics
