# Setup

Get started with **mstm.dev** - a platform for developer tools and creative experiments.

## What is mstm.dev?

**mstm.dev** is a community-driven platform where developers share tools, games, and creative projects. Everything runs in your browser, is open source, and is completely free.

## Using the Platform

### Browse Projects

Visit the [Browse page](/browse) to see all available projects organized by category:
- **Tools** - Utilities for developers
- **Games** - Puzzles and interactive experiences
- **Art** - Creative experiments and visualizations
- **Other** - Everything else

### Search and Filter

Use the [Explore page](/explore) to:
- Search by keywords
- Filter by project type
- Find mobile-friendly projects
- Discover featured content

### Project Pages

Each project has its own page at `/content/project-name`. Projects include:
- Interactive tools and applications
- Games you can play instantly
- Visual experiments
- All running client-side in your browser

## For Contributors

Want to add your own project? Check out the [Contributing Guide](/docs/contributing) to get started.

### Quick Start

1. **Fork** the repository on [GitHub](https://github.com/rxxuzi/mstm.dev)
2. **Create** your project in the `src/app/content/` directory
3. **Test** locally with `npm run dev`
4. **Submit** a pull request

See the full [Contributing Guide](/docs/contributing) for detailed instructions.
